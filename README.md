# GenericRx

GenericRx is a platform designed to map branded medicines to approved, lower-cost generic alternatives (such as Jan Aushadhi) and calculate prescription price savings.

## Tech Stack
- **Backend**: FastAPI (Python)
- **Scraping & ETL**: Scrapy, Pandas
- **Frontend**: Next.js, React
- **Databases**: PostgreSQL, MongoDB
- **DevOps**: Docker

## Getting Started

- Python 3.10+
- Git
